# Local API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Any app on the PC can read and act on the owner's calendar through Leaf, over a JSON-RPC 2.0 named pipe that is off by default and asks once per app.

**Architecture:** All protocol, ID, time, method and approval logic lives in `src/LeafCalendar.Core/Api/` and is unit-tested. The App owns only the pipe (`App/Api/ApiPipeServer.cs`), the Windows calls that name the connecting program, the approval notification, the `IApiHost` implementation (open a link, show a day or event) and the Settings › Connected apps page. Every read goes through the same queries the views use; every write goes through `EventEditor` and the outbox.

**Tech Stack:** C# 14 / .NET 10, WinUI 3, `System.IO.Pipes`, `System.Text.Json` source generation, CsWin32, xunit v3, FlaUI.

**Spec:** `docs/superpowers/specs/2026-10-13-local-api-design.md`

## Global Constraints

- Branch `feat/local-api`. Never commit or push unless the owner asks; the plan's "Commit" steps are checkpoints the owner may batch.
- Build with 0 warnings: `dotnet build LeafCalendar.slnx -c Debug` from the repo root.
- Logic tests: `dotnet test --project tests/LeafCalendar.Tests/LeafCalendar.Tests.csproj -c Debug` (one class: `--filter-class "*ClassName"`).
- Native AOT: no reflection, `System.Text.Json` only through a source-generated context, `x:Bind` only, `ItemsSource` a concrete `List<T>`, P/Invoke through CsWin32 in the App.
- Namespaces match folders (`NamespaceLayoutTests`). File-scoped namespaces. Doc comments on every public member. No column alignment.
- Files are UTF-8 with CRLF. Edit in place.
- Never log event content, emails, paths containing the user name, tokens, or params. Log method names, the client's file name (`Path.GetFileName`), counts and error codes/type names.
- Times: injected `TimeProvider`, never `DateTime.Now`. Invariant culture for every parse and format.
- US English, sentence case. All new user-visible strings are listed in **Copy** below; they ship only as the owner approves them in plan review, verbatim.
- Pipe: `PipeOptions.CurrentUserOnly | PipeOptions.FirstPipeInstance | PipeOptions.Asynchronous` (first instance), max 8 connections, 1 MB per line, 10-minute idle close.
- API version `1`.

## Review Focus

1. **A client that sends a huge line or never sends a newline** — the connection closes at 1 MB without Leaf buffering more; covered in Task 2 (`ReadLineAsync_OverLimit_Throws`).
2. **An app removed in Settings while it's still connected** — its next request gets `not_approved` and the connection closes; covered in Task 11's UI test (`RemovedApp_IsRefused`).
3. **Moving one instance of a repeating event** — the returned ID must find the moved instance (its Google ID changes to `{series}_{start}`); covered in Task 5 (`Move_SeriesInstance_ReturnsIdThatFindsIt`).
4. **A time without an offset or a date mixed with a time** — `invalid_params`, never a guessed zone; covered in Task 2 (`ReadSpan_*`).
5. **Two apps (or two connections of one app) asking at once** — one notification, both get the same answer, and Don't allow is remembered until restart; covered in Task 8 (`AskAsync_SamePathTwice_OnePrompt`, `Answer_Deny_IsRemembered`).

```csharp
    // Full paths only, one per path (the last approval wins), named, the newest MaxApprovedApps kept
    private static List<ApprovedApp> CleanApps(IReadOnlyList<ApprovedApp>? apps) =>
        [.. (apps ?? [])
            .Where(a => a is not null && !string.IsNullOrWhiteSpace(a.Path) && System.IO.Path.IsPathFullyQualified(a.Path))
            .Reverse()
            .DistinctBy(a => a.Path, StringComparer.OrdinalIgnoreCase)
            .Reverse()
            .Select(a => a with { Name = Clip(string.IsNullOrWhiteSpace(a.Name) ? System.IO.Path.GetFileNameWithoutExtension(a.Path) : a.Name.Trim(), MaxAppNameLength) })
            .TakeLast(MaxApprovedApps)];
```

```csharp
namespace LeafCalendar.Core.Api;

/// <summary>
/// The local API's error codes: JSON-RPC 2.0's numbers for protocol problems, and Leaf's own short codes (sent as
/// <c>data.code</c> under <see cref="ServerError"/>) for everything else (spec 3.4).
/// </summary>
public static class ApiErrors
{
    /// <summary>The line isn't JSON.</summary>
    public const int ParseError = -32700;

    /// <summary>The JSON isn't a JSON-RPC 2.0 request.</summary>
    public const int InvalidRequest = -32600;

    /// <summary>No method has that name.</summary>
    public const int MethodNotFound = -32601;

    /// <summary>The params are missing, of the wrong type, or out of range.</summary>
    public const int InvalidParams = -32602;

    /// <summary>Leaf failed unexpectedly.</summary>
    public const int InternalError = -32603;

    /// <summary>A Leaf error; <c>data.code</c> says which.</summary>
    public const int ServerError = -32000;
```

```csharp
using System.Text;
using System.Text.Json;

namespace LeafCalendar.Core.Api;

/// <summary>One JSON-RPC 2.0 request. <see cref="Id"/> is null for a notification (no reply); a JSON <c>null</c> id is a <see cref="JsonValueKind.Null"/> element.</summary>
public sealed record ApiRequest(JsonElement? Id, string Method, JsonElement Params);

/// <summary>
/// Reads and writes the local API's JSON-RPC 2.0 messages, one per line (spec 3.3).
/// </summary>
/// <remarks>
/// Batches aren't supported. <c>params</c> must be an object (or left out, which reads as <c>{}</c>). Error messages are
/// fixed English sentences, never exception text or anything from the request.
/// </remarks>
/// <seealso href="https://www.jsonrpc.org/specification"/>
public static class ApiMessage
{
    /// <summary>The longest line Leaf reads (1 MB); a longer one closes the connection.</summary>
    public const int MaxLineBytes = 1_048_576;

    private static readonly JsonDocumentOptions Options = new() { MaxDepth = 32 };
    private static readonly JsonElement EmptyObject = ParseElement("{}");

    /// <summary>Reads one request.</summary>
    /// <exception cref="ApiProtocolException">The line isn't JSON, isn't a JSON-RPC 2.0 request, or its params aren't an object.</exception>
    public static ApiRequest Parse(string line)
    {
        JsonDocument doc;
        try
        {
            doc = JsonDocument.Parse(line, Options);
        }
        catch (JsonException)
        {
            throw new ApiProtocolException(ApiErrors.ParseError, "Parse error.");
        }

        using (doc)
        {
            var root = doc.RootElement;
            if (root.ValueKind == JsonValueKind.Array)
            {
                throw new ApiProtocolException(ApiErrors.InvalidRequest, "Batches aren't supported.");
            }

            if (root.ValueKind != JsonValueKind.Object)
            {
                throw new ApiProtocolException(ApiErrors.InvalidRequest, "Invalid request.");
            }

            // Id: a string, a number, or null; left out for a notification
            JsonElement? id = null;
            if (root.TryGetProperty("id", out var idElement))
            {
                if (idElement.ValueKind is not (JsonValueKind.String or JsonValueKind.Number or JsonValueKind.Null))
                {
                    throw new ApiProtocolException(ApiErrors.InvalidRequest, "Invalid request.");
                }

                id = idElement.Clone();
            }

            if (!root.TryGetProperty("jsonrpc", out var version) || version.ValueKind != JsonValueKind.String || version.GetString() != "2.0"
                || !root.TryGetProperty("method", out var method) || method.ValueKind != JsonValueKind.String || string.IsNullOrEmpty(method.GetString()))
            {
                throw new ApiProtocolException(ApiErrors.InvalidRequest, "Invalid request.");
            }

            var parameters = root.TryGetProperty("params", out var p) ? p.Clone() : EmptyObject;
            if (parameters.ValueKind != JsonValueKind.Object)
            {
                throw new ApiProtocolException(ApiErrors.InvalidParams, "Invalid params.");
            }

            return new ApiRequest(id, method.GetString()!, parameters);
        }
    }

    /// <summary>A success reply.</summary>
    public static string Result(JsonElement id, JsonElement result) => Write(w =>
    {
        w.WritePropertyName("id");
        id.WriteTo(w);
        w.WritePropertyName("result");
        result.WriteTo(w);
    });

    /// <summary>An error reply; <paramref name="dataCode"/> (Leaf's short code) goes under <c>data.code</c>.</summary>
    public static string Error(JsonElement? id, int code, string message, string? dataCode = null) => Write(w =>
    {
        w.WritePropertyName("id");
        if (id is { } value)
        {
            value.WriteTo(w);
        }
        else
        {
            w.WriteNullValue();
        }

        w.WriteStartObject("error");
        w.WriteNumber("code", code);
        w.WriteString("message", message);
        if (dataCode is not null)
        {
            w.WriteStartObject("data");
            w.WriteString("code", dataCode);
            w.WriteEndObject();
        }

        w.WriteEndObject();
    });

    /// <summary>The request's id when the line is a readable request, else null.</summary>
    public static JsonElement? TryReadId(string line)
    {
        try
        {
            return Parse(line).Id;
        }
        catch (ApiProtocolException)
        {
            return null;
        }
    }

    /// <summary>The reply to a request from an app that isn't (or is no longer) approved.</summary>
    public static string NotApproved(string line) =>
        Error(TryReadId(line), ApiErrors.ServerError, "You didn't allow this app to connect to Leaf.", ApiErrors.NotApproved);

    private static string Write(Action<Utf8JsonWriter> body)
    {
        using var buffer = new MemoryStream();
        using (var w = new Utf8JsonWriter(buffer))
        {
            w.WriteStartObject();
            w.WriteString("jsonrpc", "2.0");
            body(w);
            w.WriteEndObject();
        }

        return Encoding.UTF8.GetString(buffer.GetBuffer(), 0, (int)buffer.Length);
    }

    private static JsonElement ParseElement(string json)
    {
        using var doc = JsonDocument.Parse(json);
        return doc.RootElement.Clone();
    }
}
```

```csharp
/// <summary>A line longer than the local API allows; the connection closes.</summary>
public sealed class ApiLineTooLongException : Exception

    public ApiLineTooLongException()

    /// <summary>Creates the exception.</summary>
    public ApiLineTooLongException(string message)
        : base(message)
    {

    /// <summary>Creates the exception.</summary>
    public ApiLineTooLongException(string message, Exception inner)
        : base(message, inner)
    {
    }

/// <summary>
/// Reads UTF-8 lines from a stream (a pipe connection), never holding more than <c>maxBytes</c> of one line.
/// </summary>
/// <remarks>
/// <see cref="StreamReader.ReadLineAsync()"/> has no length limit, so a client that never sends a newline could make it
/// buffer without end. Lines end at <c>\n</c>; a <c>\r</c> before it is dropped. The last line may end without one.
/// </remarks>
public sealed class ApiLineReader(Stream stream, int maxBytes = ApiMessage.MaxLineBytes)
{
    private readonly byte[] _buffer = new byte[4096];
    private readonly MemoryStream _line = new();
    private int _start;
    private int _end;

    /// <summary>The next line, or null at the end of the stream.</summary>
    /// <exception cref="ApiLineTooLongException">The line is longer than the limit.</exception>
    public async Task<string?> ReadLineAsync(CancellationToken ct)
    {
        while (true)
        {
            // A Newline In What's Buffered Ends The Line
            var newline = Array.IndexOf(_buffer, (byte)'\n', _start, _end - _start);
            if (newline >= 0)
            {
                Append(_start, newline - _start);
                _start = newline + 1;
                return Take();
            }

            Append(_start, _end - _start);
            _start = _end = 0;

            var read = await stream.ReadAsync(_buffer, ct);
            if (read == 0)
            {
                return _line.Length > 0 ? Take() : null;
            }

            _end = read;
        }
    }

    private void Append(int offset, int count)
    {
        if (_line.Length + count > maxBytes)
        {
            throw new ApiLineTooLongException();
        }

        _line.Write(_buffer, offset, count);
    }

    private string Take()
    {
        var length = (int)_line.Length;
        var bytes = _line.GetBuffer();
        if (length > 0 && bytes[length - 1] == (byte)'\r')
        {
            length--;
        }

        var text = Encoding.UTF8.GetString(bytes, 0, length);
        _line.SetLength(0);
        return text;
    }
}
```

```csharp
using System.Buffers.Text;
using System.Globalization;
using System.Text;
using LeafCalendar.Core.Events;

namespace LeafCalendar.Core.Api;

/// <summary>An event instance as an API ID names it: account, calendar, Google's event ID, and the instance's start.</summary>
public sealed record EventKey(string AccountId, string CalendarId, string EventId, DateTimeOffset Start);

/// <summary>
/// The local API's opaque IDs (spec 4): calendars carry their account, events their calendar and start, links their
/// provider. Each is base64url of its parts joined by newlines after a one-letter kind, so it is URL-safe and an ID of
/// one kind never reads as another. Reading never throws: anything malformed reads as null.
/// </summary>
public static class ApiIds
{
    private const int MaxLength = 2048;

    // Largest instant DateTimeOffset can hold, in Unix milliseconds
    private const long MaxUnixMs = 253402300799999;

    /// <summary>A calendar's ID.</summary>
    public static string Calendar(string accountId, string calendarId) => Pack("c", accountId, calendarId);

    /// <summary>An event instance's ID.</summary>
    public static string Event(CalendarOccurrence occurrence) => Event(occurrence.AccountId, occurrence.CalendarId, occurrence.EventId, occurrence.Start);

    /// <summary>An event instance's ID.</summary>
    public static string Event(string accountId, string calendarId, string eventId, DateTimeOffset start) =>
        Pack("e", accountId, calendarId, eventId, start.ToUnixTimeMilliseconds().ToString(CultureInfo.InvariantCulture));

    /// <summary>A scheduling link's ID.</summary>
    public static string Link(string providerId, string linkId) => Pack("l", providerId, linkId);

    /// <summary>The calendar a <see cref="Calendar"/> ID names, or null.</summary>
    public static (string AccountId, string CalendarId)? ReadCalendar(string? id) =>
        Unpack(id, "c", 2) is { } p ? (p[0], p[1]) : null;

    /// <summary>The event instance an <see cref="Event(CalendarOccurrence)"/> ID names, or null.</summary>
    public static EventKey? ReadEvent(string? id) =>
        Unpack(id, "e", 4) is { } p && long.TryParse(p[3], NumberStyles.AllowLeadingSign, CultureInfo.InvariantCulture, out var ms) && Math.Abs(ms) <= MaxUnixMs
            ? new EventKey(p[0], p[1], p[2], DateTimeOffset.FromUnixTimeMilliseconds(ms))
            : null;

    /// <summary>The scheduling link a <see cref="Link"/> ID names, or null.</summary>
    public static (string ProviderId, string LinkId)? ReadLink(string? id) =>
        Unpack(id, "l", 2) is { } p ? (p[0], p[1]) : null;

    private static string Pack(string kind, params string[] parts)
    {
        if (parts.Any(p => string.IsNullOrEmpty(p) || p.Contains('\n', StringComparison.Ordinal)))
        {
            throw new ArgumentException("ID parts must be non-empty and on one line.", nameof(parts));
        }

        return Base64Url.EncodeToString(Encoding.UTF8.GetBytes(kind + "\n" + string.Join('\n', parts)));
    }

    private static string[]? Unpack(string? id, string kind, int count)
    {
        if (string.IsNullOrEmpty(id) || id.Length > MaxLength)
        {
            return null;
        }

        byte[] bytes;
        try
        {
            bytes = Base64Url.DecodeFromChars(id);
        }
        catch (FormatException)
        {
            return null;
        }

        var parts = Encoding.UTF8.GetString(bytes).Split('\n');
        return parts.Length == count + 1 && parts[0] == kind && parts.Skip(1).All(p => p.Length > 0) ? parts[1..] : null;
    }
}
```

```csharp
            : null;

    /// <summary>Reads a <c>yyyy-MM-dd</c> date, or null.</summary>
    public static DateOnly? ReadDate(string? text) =>
        DateOnly.TryParseExact(text, "yyyy-MM-dd", CultureInfo.InvariantCulture, DateTimeStyles.None, out var date) ? date : null;

    /// Reads a start and end: two dates (all-day, as UTC midnights like <see cref="Events.CalendarOccurrence"/>) or two
    /// instants. The end must be after the start.
    /// </summary>
    /// <exception cref="ApiProtocolException">Missing, mixed, without an offset, or backwards (<see cref="ApiErrors.InvalidParams"/>).</exception>
```

```csharp
using System.Text.Json;
using LeafCalendar.Core.Diagnostics;

namespace LeafCalendar.Core.Api;

/// <summary>
/// Answers one line of the local API (spec 3.1, 4): reads the request, runs its method, and writes the reply.
/// </summary>
/// <remarks>
/// Nothing escapes: protocol problems get JSON-RPC codes, Leaf's own problems <see cref="ApiErrors.ServerError"/> with a
/// short code, and anything unexpected <see cref="ApiErrors.InternalError"/> with a fixed message (the exception's type
/// is logged, never its text). Requests are logged by method name only, as a breadcrumb.
/// </remarks>
public sealed class ApiDispatcher(ApiContext context, AppLog log)
{
    /// <summary>The API's version; it changes only when a method or field is removed or changes meaning.</summary>
    public const int ApiVersion = 1;

    /// <summary>The reply line for <paramref name="line"/>, or null for a notification.</summary>
    public async Task<string?> HandleAsync(string line, CancellationToken ct)
    {
        ApiRequest request;
        try
        {
            request = ApiMessage.Parse(line);
        }
        catch (ApiProtocolException ex)
        {
            return ApiMessage.Error(ApiMessage.TryReadId(line), ex.Code, ex.Message);
        }

        log.Trace("api.request", $"method={request.Method}");
        try
        {
            var result = await RunAsync(request, ct);
            return request.Id is { } id ? ApiMessage.Result(id, result) : null;
        }
        catch (ApiProtocolException ex)
        {
            return Reply(request, ex.Code, ex.Message, null);
        }
        catch (ApiException ex)
        {
            return Reply(request, ApiErrors.ServerError, ex.Message, ex.Code);
        }
        catch (OperationCanceledException) when (ct.IsCancellationRequested)
        {
            throw;
        }
        catch (Exception ex)
        {
            // The type only, never the text (it can carry event content)
            log.Info("api.failed", $"method={request.Method} error={ex.GetType().Name}");
            return Reply(request, ApiErrors.InternalError, "Leaf couldn't do that.", null);
        }
    }

    private static string? Reply(ApiRequest request, int code, string message, string? dataCode) =>
        request.Id is { } id ? ApiMessage.Error(id, code, message, dataCode) : null;

    private Task<JsonElement> RunAsync(ApiRequest r, CancellationToken ct) => r.Method switch
    {
        "leaf.hello" => Task.FromResult(ApiCalendars.Hello(context, ApiParams.Read(r.Params, ApiJsonContext.Default.HelloParams))),
        "calendars.list" => Task.FromResult(ApiCalendars.List(context, ApiParams.Read(r.Params, ApiJsonContext.Default.NoParams))),
        _ => throw new ApiProtocolException(ApiErrors.MethodNotFound, "Unknown method."),
    };
}
```

```csharp
using System.Text.Json;
using LeafCalendar.Core.Alerts;
using LeafCalendar.Core.Data;
using LeafCalendar.Core.Events;
using LeafCalendar.Core.Views;
using Microsoft.Data.Sqlite;

namespace LeafCalendar.Core.Api;

/// <summary>The event methods: list, get, create, move (spec 4).</summary>
internal static class ApiEvents
{
    // The longest range events.list reads
    private static readonly TimeSpan MaxListRange = TimeSpan.FromDays(366);

    // =========================================================================
    // READING
    // =========================================================================

    // Events overlapping [start, end) on the calendars shown in Leaf, as the calendar draws them
    public static JsonElement List(ApiContext context, RangeParams p)
    {
        var start = ApiTime.ReadInstant(p.Start) ?? throw ApiTime.Invalid("start must be a time with an offset.");
        var end = ApiTime.ReadInstant(p.End) ?? throw ApiTime.Invalid("end must be a time with an offset.");
        if (end <= start || end - start > MaxListRange)
        {
            throw ApiTime.Invalid("end must be after start, at most 366 days later.");
        }

        HashSet<(string, string)>? only = p.CalendarIds is null
            ? null
            : [.. p.CalendarIds.Select(id => ApiIds.ReadCalendar(id) ?? throw ApiTime.Invalid("calendarIds holds an ID that isn't a calendar's."))];

        var zone = context.Host.Zone;
        var from = DateOnly.FromDateTime(TimeZoneInfo.ConvertTime(start, zone).DateTime);
        var to = DateOnly.FromDateTime(TimeZoneInfo.ConvertTime(end, zone).DateTime).AddDays(1);

        using var conn = context.Database.Open();
        List<EventResult> result = [.. OccurrenceQuery.Load(conn, from, to, zone, context.Host.Settings.ShowDeclined)
            .Where(o => o.EndIn(zone) > start && o.StartIn(zone) < end)
            .Where(o => only is null || only.Contains((o.AccountId, o.CalendarId)))
            .Select(o => Summary(conn, o, zone))];
        return ApiParams.Write(result, ApiJsonContext.Default.ListEventResult);
    }

    // One instance with its description (plain text) and guests (rooms left out)
    public static JsonElement Get(ApiContext context, IdParams p)
    {
        using var conn = context.Database.Open();
        var o = Find(conn, context, p.Id);
        var zone = context.Host.Zone;
        var details = Details(conn, o);
        List<Editing.Guest> guests;
        try
        {
            guests = [.. context.Editor.Load(o).Guests];
        }
        catch (InvalidOperationException)
        {
            throw NotFound();
        }

        var summary = Summary(conn, o, zone);
        var result = new EventDetailResult(
            summary.Id, summary.CalendarId, summary.Title, summary.Start, summary.End, summary.AllDay, summary.Location,
            summary.Response, summary.Color, summary.MeetingLink, details?.Description ?? "",
            [.. guests.Where(g => !g.IsResource).Select(g => new GuestResult(g.Name, g.Email, Response(g.Response), g.IsOrganizer))]);
        return ApiParams.Write(result, ApiJsonContext.Default.EventDetailResult);
    }

    // =========================================================================
    // SHARED
    // =========================================================================

    /// <summary>The instance an event ID names, as it is now (it may have moved since the ID was made).</summary>
    public static CalendarOccurrence Find(SqliteConnection conn, ApiContext context, string? id)
    {
        var key = ApiIds.ReadEvent(id) ?? throw ApiTime.Invalid("id isn't an event ID.");
        return OccurrenceLookup.Find(conn, key.AccountId, key.CalendarId, key.EventId, key.Start, context.Host.Zone) ?? throw NotFound();
    }

    /// <summary>Your answer as the API writes it.</summary>
    public static string Response(ResponseStatus response) => response switch
    {
        ResponseStatus.Accepted => "accepted",
        ResponseStatus.Tentative => "tentative",
        ResponseStatus.Declined => "declined",
        _ => "needsAction",
    };

    public static ApiException NotFound() => new(ApiErrors.NotFound, "No event with that ID.");

    private static EventResult Summary(SqliteConnection conn, CalendarOccurrence o, TimeZoneInfo zone)
    {
        var details = Details(conn, o);
        return new EventResult(
            ApiIds.Event(o),
            ApiIds.Calendar(o.AccountId, o.CalendarId),
            o.Title,
            o.IsAllDay ? ApiTime.Write(o.AllDayStart) : ApiTime.Write(o.Start, zone),
            o.IsAllDay ? ApiTime.Write(o.AllDayEnd) : ApiTime.Write(o.End, zone),
            o.IsAllDay,
            details?.Location,
            Response(o.SelfResponse),
            EventColors.ResolveAccent(o.ColorId, o.CalendarColor),
            JoinPicker.KnownHost(details?.ConferenceUri)?.AbsoluteUri);
    }

    // The stored event's details, or null when it's gone or unreadable
    private static EventDetails? Details(SqliteConnection conn, CalendarOccurrence o)
    {
        if (EventStore.Get(conn, o.AccountId, o.CalendarId, o.EventId) is not { } stored)
        {
            return null;
        }
```

```csharp
    /// <summary>The most guests <c>events.create</c> takes.</summary>
    public const int MaxGuests = 100;

    private const int MaxTitleLength = 1024;
    private const int MaxLocationLength = 1024;
    private const int MaxDescriptionLength = 8192;

    // =========================================================================
    // EDITS (through the editor and the outbox, like the app)
    // =========================================================================

    // A new event on the chosen calendar, else where new events go; invitations follow notifyGuests (default on), like Save and quiet save
    public static JsonElement Create(ApiContext context, CreateParams p)
    {
        if (p.Title is null || p.Title.Length > MaxTitleLength)
        {
            throw ApiTime.Invalid("title is required, at most 1,024 characters.");
        }

        if ((p.Location?.Length ?? 0) > MaxLocationLength || (p.Description?.Length ?? 0) > MaxDescriptionLength)
        {
            throw ApiTime.Invalid("location is at most 1,024 characters and description at most 8,192.");
        }

        var (start, end, allDay) = ApiTime.ReadSpan(p.Start, p.End);
        var guests = Guests(p.Guests);

        CalendarInfo target;
        using (var conn = context.Database.Open())
        {
            var accounts = AccountStore.GetAll(conn);
            if (accounts.Count == 0)
            {
                throw new ApiException(ApiErrors.NotSignedIn, "No Google account is signed in.");
            }

            var calendars = CalendarStore.GetAll(conn);
            var settings = context.Host.Settings;
            if (p.CalendarId is not null)
            {
                var (accountId, calendarId) = ApiIds.ReadCalendar(p.CalendarId) ?? throw ApiTime.Invalid("calendarId isn't a calendar ID.");
                target = calendars.FirstOrDefault(c => c.AccountId == accountId && c.Id == calendarId && c.IsVisible)
                    ?? throw new ApiException(ApiErrors.NotFound, "No calendar with that ID.");
                if (target.AccessRole is not ("owner" or "writer"))
                {
                    throw new ApiException(ApiErrors.ReadOnly, "You can't change that.");
                }
            }
            else
            {
                target = DefaultCalendar.Pick(calendars, accounts.Select(a => a.Id).ToHashSet(), settings.DefaultCalendar, mainAccountId: settings.MainAccountId)
                    ?? throw new ApiException(ApiErrors.ReadOnly, "You can't change that.");
            }
        }

        var draft = new EventDraft
        {
            AccountId = target.AccountId,
            CalendarId = target.Id,
            Title = p.Title,
            Start = start,
            End = end,
            IsAllDay = allDay,
            TimeZone = allDay ? null : TimeZoneCatalog.IanaId(context.Host.Zone),
            Location = p.Location ?? "",
            Description = Html(p.Description),
            Guests = [.. guests.Select(email => new Guest(email))],
        };
        var id = context.Editor.Create(draft, sendUpdates: p.NotifyGuests ?? true);
        return ApiParams.Write(new IdResult(ApiIds.Event(target.AccountId, target.Id, id, start)), ApiJsonContext.Default.IdResult);
    }

    // A drag: one scope for a repeating event, guests told; the new ID finds the moved instance (a split series has none yet)
    public static JsonElement Move(ApiContext context, MoveParams p)
    {
        var scope = p.Scope switch
        {
            null or "this" => EditScope.This,
            "following" => EditScope.Following,
            "all" => EditScope.All,
            _ => throw ApiTime.Invalid("scope must be this, following, or all."),
        };
        var (start, end, allDay) = ApiTime.ReadSpan(p.Start, p.End);

        CalendarOccurrence o;
        using (var conn = context.Database.Open())
        {
            o = Find(conn, context, p.Id);
        }

        if (!context.Editor.Permissions(o).CanEdit)
        {
            throw new ApiException(ApiErrors.ReadOnly, "You can't change that.");
        }

        context.Editor.Move([new EventMove(o, start, end, allDay)], scope, sendUpdates: true);

        if (scope == EditScope.Following)
        {
            return ApiParams.Write(new IdResult(null), ApiJsonContext.Default.IdResult);
        }

        using (var conn = context.Database.Open())
        {
            return ApiParams.Write(new IdResult(Relocate(conn, context, o, start) is { } moved ? ApiIds.Event(moved) : null), ApiJsonContext.Default.IdResult);
        }
    }

    // Where a moved instance landed: same calendar, same event or series, starting at the new time (a moved instance of a
    // series gets Google's {series}_{start} ID, so the old ID can't find it)
    private static CalendarOccurrence? Relocate(SqliteConnection conn, ApiContext context, CalendarOccurrence before, DateTimeOffset start)
    {
        var zone = context.Host.Zone;
        var series = before.RecurringEventId ?? before.EventId;
        var day = DateOnly.FromDateTime(TimeZoneInfo.ConvertTime(start, zone).DateTime);
        return OccurrenceQuery.Load(conn, day.AddDays(-1), day.AddDays(2), zone, includeDeclined: true, keepSharedCopies: true)
            .FirstOrDefault(o => o.AccountId == before.AccountId && o.CalendarId == before.CalendarId && o.Start == start
                && (o.EventId == before.EventId || o.EventId == series || o.RecurringEventId == series));
    }

    // Guests as the editor checks them: valid addresses only, repeats (any case) dropped, at most MaxGuests
    private static List<string> Guests(List<string>? emails)
    {
        var result = new List<string>();
        foreach (var raw in emails ?? [])
        {
            var email = ContactSearch.ValidEmail(raw) ?? throw ApiTime.Invalid("guests holds an address that isn't an email address.");
            if (!result.Contains(email, StringComparer.OrdinalIgnoreCase))
            {
                result.Add(email);
            }
        }

        return result.Count <= MaxGuests ? result : throw ApiTime.Invalid("guests holds more than 100 addresses.");
    }

    // Plain text to Leaf's description HTML: every character escaped, each line its own line
    private static string Html(string? text) =>
        string.IsNullOrEmpty(text) ? "" : DescriptionHtml.Normalize(string.Join("<br>", text.ReplaceLineEndings("\n").Split('\n').Select(WebUtility.HtmlEncode)));
```

```csharp
using System.Text.Json;
using LeafCalendar.Core.People;
using LeafCalendar.Core.Scheduling;

namespace LeafCalendar.Core.Api;

/// <summary>The scheduling methods: links, open times, and a booking link for one time (spec 4), through the signed-in providers.</summary>
internal static class ApiScheduling
{
    // The longest range scheduling.openTimes reads, and the most guests a booking link carries
    private static readonly TimeSpan MaxRange = TimeSpan.FromDays(31);
    private const int MaxGuests = 20;

    public static async Task<JsonElement> LinksAsync(ApiContext context, NoParams _, CancellationToken ct)
    {
        RequireConnected(context);
        var links = await context.Scheduling.GetLinksAsync(ct);
        List<LinkResult> result = [.. links.Select(l => new LinkResult(ApiIds.Link(l.ProviderId, l.Id), context.Scheduling.Get(l.ProviderId)?.Name ?? l.ProviderId, l.Name, l.Minutes, l.AllowsGuests))];
        return ApiParams.Write(result, ApiJsonContext.Default.ListLinkResult);
    }

    public static async Task<JsonElement> OpenTimesAsync(ApiContext context, OpenTimesParams p, CancellationToken ct)
    {
        var start = ApiTime.ReadInstant(p.Start) ?? throw ApiTime.Invalid("start must be a time with an offset.");
        var end = ApiTime.ReadInstant(p.End) ?? throw ApiTime.Invalid("end must be a time with an offset.");
        if (end <= start || end - start > MaxRange)
        {
            throw ApiTime.Invalid("end must be after start, at most 31 days later.");
        }

        var (link, provider) = await FindLinkAsync(context, p.LinkId, ct);
        if (provider is not IOpenTimesSource source)
        {
            throw NotConnected();
        }

        try
        {
            var times = await source.GetOpenTimesAsync(link.Id, start.ToUniversalTime(), end.ToUniversalTime(), ct);
            List<TimeRangeResult> result = [.. times.Select(t => new TimeRangeResult(ApiTime.Write(t.Start, context.Host.Zone), ApiTime.Write(t.End, context.Host.Zone)))];
            return ApiParams.Write(result, ApiJsonContext.Default.ListTimeRangeResult);
        }
        catch (SchedulingAuthException)
        {
            context.Scheduling.MarkNeedsReconnect(provider.Id);
            throw NotConnected();
        }
        catch (SchedulingUnavailableException)
        {
            throw new ApiException(ApiErrors.Unavailable, "The scheduling provider couldn't be reached. Try again later.");
        }
    }

    public static async Task<JsonElement> TimeLinkAsync(ApiContext context, TimeLinkParams p, CancellationToken ct)
    {
        var start = ApiTime.ReadInstant(p.Start) ?? throw ApiTime.Invalid("start must be a time with an offset.");
        if ((p.Guests?.Count ?? 0) > MaxGuests)
        {
            throw ApiTime.Invalid("guests holds more than 20 people.");
        }

        List<Contact> guests = [.. (p.Guests ?? []).Select(g =>
            new Contact((g.Name ?? "").Trim(), ContactSearch.ValidEmail(g.Email) ?? throw ApiTime.Invalid("guests holds an address that isn't an email address.")))];

        var (link, provider) = await FindLinkAsync(context, p.LinkId, ct);
        if (provider is not ITimeLinkBuilder builder)
        {
            throw NotConnected();
        }

        var url = builder.TimeLink(link, start.ToUniversalTime(), context.Host.Zone, guests);
        return ApiParams.Write(new UrlResult(url.AbsoluteUri), ApiJsonContext.Default.UrlResult);
    }

    // The link a link ID names, among the signed-in provider's current links
    private static async Task<(SchedulingLink Link, ISchedulingProvider Provider)> FindLinkAsync(ApiContext context, string? id, CancellationToken ct)
    {
        var (providerId, linkId) = ApiIds.ReadLink(id) ?? throw ApiTime.Invalid("linkId isn't a scheduling link ID.");
        RequireConnected(context);
        var provider = context.Scheduling.Get(providerId) ?? throw NotConnected();
        var links = await context.Scheduling.GetLinksAsync(ct);
        if (context.Scheduling.StateOf(providerId) != ProviderState.SignedIn)
        {
            throw NotConnected();
        }

        var link = links.FirstOrDefault(l => l.ProviderId == providerId && l.Id == linkId)
            ?? throw new ApiException(ApiErrors.NotFound, "No scheduling link with that ID.");
        return (link, provider);
    }

    private static void RequireConnected(ApiContext context)
    {
        if (context.Scheduling.Connected.Count == 0)
        {
            throw NotConnected();
        }
    }

    private static ApiException NotConnected() => new(ApiErrors.NotConnected, "No scheduling provider is connected.");
}
```

```csharp
using System.Security.Cryptography;

namespace LeafCalendar.Core.Api;

/// <summary>An approval waiting on your answer: the notification's token, and the program asking.</summary>
public sealed record PendingApproval(string Token, string Path, string Name);

/// <summary>
/// The one-time question "Allow {app} to connect?" (spec 3.5).
/// </summary>
/// <remarks>
/// One question per program path at a time (case ignored): other connections from it wait on the same answer. No answer
/// within <see cref="Wait"/> is a no, but isn't remembered; Don't allow is remembered until Leaf restarts, so a retrying
/// app can't keep prompting. Tokens are 128 random bits, so a notification's arguments can't be guessed. Approved paths
/// are saved by the caller (in settings) before it calls <see cref="Answer"/>.
/// </remarks>
public sealed class ApiApprovals(TimeProvider time)
{
    /// <summary>How long a connection waits for your answer.</summary>
    public static readonly TimeSpan Wait = TimeSpan.FromSeconds(60);

    private readonly Lock _gate = new();
    private readonly Dictionary<string, (PendingApproval Request, TaskCompletionSource<bool> Answer)> _pending = new(StringComparer.OrdinalIgnoreCase);
    private readonly HashSet<string> _refused = new(StringComparer.OrdinalIgnoreCase);

    /// <summary>True when you chose Don't allow for this path since Leaf started.</summary>
    public bool IsRefused(string path)
    {
        lock (_gate)
        {
            return _refused.Contains(path);
        }
    }

    /// <summary>
    /// Asks once for <paramref name="path"/> (calling <paramref name="prompt"/> to show the question) and waits for the
    /// answer; false when refused before, refused now, or unanswered within <see cref="Wait"/>.
    /// </summary>
    public async Task<bool> AskAsync(string path, string name, Action<PendingApproval> prompt, CancellationToken ct)
    {
        TaskCompletionSource<bool> answer;
        PendingApproval? asked = null;
        lock (_gate)
        {
            if (_refused.Contains(path))
            {
                return false;
            }

            if (_pending.TryGetValue(path, out var waiting))
            {
                answer = waiting.Answer;
            }
            else
            {
                asked = new PendingApproval(Convert.ToHexStringLower(RandomNumberGenerator.GetBytes(16)), path, name);
                answer = new TaskCompletionSource<bool>(TaskCreationOptions.RunContinuationsAsynchronously);
                _pending[path] = (asked, answer);
            }
        }

        if (asked is not null)
        {
            prompt(asked);
        }

        try
        {
            return await answer.Task.WaitAsync(Wait, time, ct);
        }
        catch (TimeoutException)
        {
            lock (_gate)
            {
                if (_pending.TryGetValue(path, out var waiting) && waiting.Answer == answer)
                {
                    _pending.Remove(path);
                }
            }

            return false;
        }
    }

    /// <summary>The question a notification's token belongs to, or null when it was answered or timed out.</summary>
    public PendingApproval? Find(string token)
    {
        lock (_gate)
        {
            return _pending.Values.FirstOrDefault(p => p.Request.Token == token).Request;
        }
    }

    /// <summary>Answers a question; a no is remembered until Leaf restarts. An unknown token does nothing.</summary>
    public void Answer(string token, bool allow)
    {
        TaskCompletionSource<bool>? answer = null;
        lock (_gate)
        {
            foreach (var (path, waiting) in _pending)
            {
                if (waiting.Request.Token == token)
                {
                    answer = waiting.Answer;
                    _pending.Remove(path);
                    if (!allow)
                    {
                        _refused.Add(path);
                    }

                    break;
                }
            }
        }

        answer?.TrySetResult(allow);
    }
}
```

```csharp
using System.IO.Pipes;
using System.Text;
using LeafCalendar.Core.Api;
using LeafCalendar.Core.Diagnostics;
using Windows.Win32;
using Windows.Win32.System.Threading;

namespace LeafCalendar.App.Api;

/// <summary>
/// The local API's named pipe (spec 3.3): locked to the current Windows user, never shared with another program that
/// took the name first, at most <see cref="MaxConnections"/> apps at once.
/// </summary>
/// <remarks>
/// Each connection reads lines (<see cref="ApiLineReader"/>, 1 MB each), answers them in order through the
/// <see cref="ApiDispatcher"/>, and closes after 10 minutes without a request. Before a request runs, the connecting
/// program (its file path, from Windows) must be approved; a new one is asked once per connection, and one removed in
/// Settings is refused at its next request. Nothing escapes: a failing connection is logged by its error type and closed.
/// </remarks>
internal sealed class ApiPipeServer(string name, ApiDispatcher dispatcher, Func<string, bool> isApproved, Func<string, CancellationToken, Task<bool>> approve, AppLog log) : IAsyncDisposable
{
    /// <summary>The most apps connected at once.</summary>
    public const int MaxConnections = 8;

    private static readonly TimeSpan IdleLimit = TimeSpan.FromMinutes(10);

    private readonly CancellationTokenSource _stop = new();
    private readonly SemaphoreSlim _slots = new(MaxConnections, MaxConnections);
    private Task? _accepting;

    /// <summary>Opens the pipe; false when another program already holds the name (the API stays off).</summary>
    public bool Start()
    {
        NamedPipeServerStream first;
        try
        {
            first = Create(firstInstance: true);
        }
        catch (Exception ex) when (ex is UnauthorizedAccessException or IOException)
        {
            log.Info("api.name-taken", $"error={ex.GetType().Name}");
            return false;
        }

        _accepting = Task.Run(() => AcceptAsync(first, _stop.Token));
        log.Info("api.started");
        return true;
    }

    /// <inheritdoc />
    public async ValueTask DisposeAsync()
    {
        await _stop.CancelAsync();
        if (_accepting is { } accepting)
        {
            await accepting;
        }

        _stop.Dispose();
        log.Info("api.stopped");
    }

    private NamedPipeServerStream Create(bool firstInstance) =>
        new(name, PipeDirection.InOut, MaxConnections, PipeTransmissionMode.Byte,
            PipeOptions.Asynchronous | PipeOptions.CurrentUserOnly | (firstInstance ? PipeOptions.FirstPipeInstance : PipeOptions.None));

    // One instance waits at a time; a connected one is handed off and the next is made once a slot is free
    private async Task AcceptAsync(NamedPipeServerStream first, CancellationToken ct)
    {
        NamedPipeServerStream? waiting = first;
        try
        {
            await _slots.WaitAsync(ct);
            while (true)
            {
                await waiting.WaitForConnectionAsync(ct);
                var connected = waiting;
                waiting = null;
                _ = Task.Run(() => ServeAsync(connected, ct), CancellationToken.None);

                await _slots.WaitAsync(ct);
                waiting = Create(firstInstance: false);
            }
        }
        catch (OperationCanceledException)
        {
            // Stopped
        }
        catch (Exception ex)
        {
            log.Info("api.accept.failed", $"error={ex.GetType().Name}");
        }
        finally
        {
            if (waiting is not null)
            {
                await waiting.DisposeAsync();
            }
        }
    }

    private async Task ServeAsync(NamedPipeServerStream pipe, CancellationToken ct)
    {
        try
        {
            await using (pipe)
            {
                if (ClientPath(pipe) is not { } path)
                {
                    log.Info("api.client.unknown");
                    return;
                }

                var file = Path.GetFileName(path);
                log.Info("api.connected", $"client={file}");
                var reader = new ApiLineReader(pipe);
                var writer = new StreamWriter(pipe, new UTF8Encoding(false), 4096, leaveOpen: true) { AutoFlush = true, NewLine = "\n" };
                var asked = false;
                while (true)
                {
                    using var idle = CancellationTokenSource.CreateLinkedTokenSource(ct);
                    idle.CancelAfter(IdleLimit);
                    if (await reader.ReadLineAsync(idle.Token) is not { } line)
                    {
                        return;
                    }

                    if (line.Length == 0)
                    {
                        continue;
                    }

                    // Approved Now, Or Asked Once On This Connection (an app removed in Settings is refused here)
                    if (!isApproved(path))
                    {
                        if (asked || !await approve(path, ct))
                        {
                            log.Info("api.refused", $"client={file}");
                            await writer.WriteLineAsync(ApiMessage.NotApproved(line));
                            return;
                        }

                        asked = true;
                    }

                    if (await dispatcher.HandleAsync(line, ct) is { } reply)
                    {
                        await writer.WriteLineAsync(reply);
                    }
                }
            }
        }
        catch (OperationCanceledException)
        {
            // Idle too long, or the API stopped
        }
        catch (ApiLineTooLongException)
        {
            log.Info("api.line.too-long");
        }
        catch (IOException)
        {
            // The app went away
        }
        catch (Exception ex)
        {
            log.Info("api.connection.failed", $"error={ex.GetType().Name}");
        }
        finally
        {
            _slots.Release();
        }
    }

    // The connecting program's full path, from Windows (null when it can't be read, such as a process that already ended)
    private static unsafe string? ClientPath(NamedPipeServerStream pipe)
    {
        if (!PInvoke.GetNamedPipeClientProcessId(pipe.SafePipeHandle, out var pid))
        {
            return null;
        }

        using var process = PInvoke.OpenProcess_SafeHandle(PROCESS_ACCESS_RIGHTS.PROCESS_QUERY_LIMITED_INFORMATION, false, pid);
        if (process.IsInvalid)
        {
            return null;
        }

        Span<char> buffer = stackalloc char[1024];
        var size = (uint)buffer.Length;
        return PInvoke.QueryFullProcessImageName(process, PROCESS_NAME_FORMAT.PROCESS_NAME_WIN32, buffer, ref size)
            ? new string(buffer[..(int)size])
            : null;
    }
}
```

```csharp
using System.Diagnostics;
using LeafCalendar.App.Api;
using LeafCalendar.Core.Alerts;
using LeafCalendar.Core.Api;
using LeafCalendar.Core.Data;
using LeafCalendar.Core.Events;
using LeafCalendar.Core.Settings;
using LeafCalendar.Core.Views;
using Microsoft.UI.Dispatching;
using Windows.ApplicationModel;

namespace LeafCalendar.App;

// =========================================================================
// LOCAL API (spec 2026-10-13-local-api-design.md): the pipe runs while Settings › Connected apps is on
// =========================================================================
public partial class App
{
    private ApiPipeServer? _api;
    private ApiApprovals? _approvals;
    private bool _apiOn;

    // Starts or stops the pipe to match the switch (at startup and after every settings change); nothing may escape
    private void UpdateApi()
    {
        if (_services is not { } services)
        {
            return;
        }

        try
        {
            var on = CurrentSettings().AllowApiConnections;
            if (on == _apiOn)
            {
                return;
            }

            _apiOn = on;
            if (!on)
            {
                var running = _api;
                _api = null;
                services.ApiNameTaken = false;
                if (running is not null)
                {
                    _ = running.DisposeAsync().AsTask();
                }

                return;
            }

            _approvals ??= new ApiApprovals(services.Time);
            var context = new ApiContext(services.Database, services.Editor, services.Scheduling, new ApiHost(this), services.Time, LeafVersion(), services.Options.Profile);
            var server = new ApiPipeServer(
                ApiClients.PipeName(Environment.UserName, services.Options.Profile),
                new ApiDispatcher(context, services.Log),
                path => CurrentSettings().IsApproved(path),
                ApproveAsync,
                services.Log);
            var started = server.Start();
            _api = started ? server : null;
            services.ApiNameTaken = !started;
        }
        catch (Exception ex)
        {
            services.Log.Info("api.update.failed", $"error={ex.GetType().Name}");
        }
    }

    // A new program asks: one notification, a 60-second wait, and the notification goes once it's answered or timed out
    private async Task<bool> ApproveAsync(string path, CancellationToken ct)
    {
        PendingApproval? shown = null;
        var allowed = await _approvals!.AskAsync(path, ClientName(path), request =>
        {
            shown = request;
            _dispatcher?.TryEnqueue(() => ShowApproval(request));
        }, ct);

        if (shown is { } asked)
        {
            _ = _notifier?.RemoveAsync(ToastContent.ApprovalTag(asked.Token), ToastContent.ApiGroup);
        }

        return allowed;
    }

    private void ShowApproval(PendingApproval request)
    {
        try
        {
            _notifier?.Show(ToastContent.ApproveApp(request, ApiClients.IsGeneralRuntime(request.Path), _services!.Options.Profile, CurrentSettings().NotificationSound));
        }
        catch (Exception ex)
        {
            // A dispatcher callback, so nothing may escape
            _services?.Log.Info("api.prompt.failed", $"error={ex.GetType().Name}");
        }
    }

    // Allow or Don't allow on the notification (from HandleToast, on the UI thread): an approval is saved before the waiting connection hears it
    private void AnswerApproval(string token, bool allow)
    {
        if (_approvals?.Find(token) is not { } request)
        {
            return;
        }

        if (allow)
        {
            UpdateSettings(s => s.WithApprovedApp(new ApprovedApp(request.Path, request.Name, _services!.Time.GetUtcNow())));
        }

        _approvals.Answer(token, allow);
        _services!.Log.Info(allow ? "api.allowed" : "api.denied", $"client={Path.GetFileName(request.Path)}");
    }

    // A settings change from outside Settings: through the calendar's view model when it exists (so it shows at once), else straight to the database
    private void UpdateSettings(Func<LeafSettings, LeafSettings> change)
    {
        if (_calendar is { } calendar)
        {
            calendar.Update(change);
            return;
        }

        using var conn = _services!.Database.Open();
        SettingsStore.Save(conn, change(SettingsStore.Load(conn)).Normalize());
    }

    // The program's product name, else its description, else its file name
    private static string ClientName(string path)
    {
        try
        {
            var info = FileVersionInfo.GetVersionInfo(path);
            var name = !string.IsNullOrWhiteSpace(info.ProductName) ? info.ProductName : info.FileDescription;
            if (!string.IsNullOrWhiteSpace(name))
            {
                return name.Trim();
            }
        }
        catch (Exception ex) when (ex is FileNotFoundException or IOException or UnauthorizedAccessException)
        {
            // The file name below
        }

        return Path.GetFileNameWithoutExtension(path);
    }

    private static string LeafVersion()
    {
        var v = Package.Current.Id.Version;
        return $"{v.Major}.{v.Minor}.{v.Build}";
    }

    /// <summary>The app as the local API sees it: the shown zone and settings, Leaf's link launcher, and the main window.</summary>
    private sealed class ApiHost(App app) : IApiHost
    {
        public TimeZoneInfo Zone => DisplayZone.Resolve(null, app.CurrentSettings().PrimaryTimeZone, app._zone.Zone);

        public LeafSettings Settings => app.CurrentSettings();

        public Task<bool> OpenLinkAsync(Uri link) => app._services!.LaunchAsync(link);

        public void ShowDay(DateOnly day) => app._dispatcher?.TryEnqueue(() =>
        {
            try
            {
                app.ShowMainWindow();
                app._dispatcher.TryEnqueue(DispatcherQueuePriority.Low, () => app._window?.ShowDay(day));
            }
            catch (Exception ex)
            {
                app._services?.Log.Info("api.show-day.failed", $"error={ex.GetType().Name}");
            }
        });

        public void ShowEvent(CalendarOccurrence occurrence) => app._dispatcher?.TryEnqueue(() => app.RevealEvent(occurrence));
    }
}
```

```csharp
using LeafCalendar.App.Controls;
using Microsoft.UI.Xaml;
using Microsoft.UI.Xaml.Automation;
using Microsoft.UI.Xaml.Controls;
using Microsoft.UI.Xaml.Navigation;

namespace LeafCalendar.App.Views.Settings;

/// <summary>
/// Settings › Connected apps (local API spec, section 6): the switch that lets other apps on this PC connect (off by
/// default), the apps you allowed with a Remove button each, a card when another program holds Leaf's pipe name, and a
/// link to the developer reference. Changes save right away; a removed app is refused at its next request.
/// </summary>
public sealed partial class ConnectedAppsPage : Page
{
    private static readonly Uri DocsUri = new("https://github.com/artistro08/leaf-calendar/blob/main/docs/api.md");

    private SettingsContext _context = null!;

    // True while the saved values are being shown (the switch's change event is ignored meanwhile)
    private bool _loading = true;

    /// <summary>Creates the page.</summary>
    public ConnectedAppsPage()
    {
        InitializeComponent();
        ScrollIndicator.ShowOnHover(PageScroll);
    }

    /// <inheritdoc />
    protected override void OnNavigatedTo(NavigationEventArgs e)
    {
        _context = (SettingsContext)e.Parameter;
        _context.Host.SettingsChanged += OnSettingsChanged;
        _context.Services.ApiStateChanged += OnApiStateChanged;
        Load();
    }

    /// <inheritdoc />
    protected override void OnNavigatedFrom(NavigationEventArgs e)
    {
        _context.Host.SettingsChanged -= OnSettingsChanged;
        _context.Services.ApiStateChanged -= OnApiStateChanged;
    }

    private void OnSettingsChanged(object? sender, EventArgs e) => Load();

    // Raised on whatever thread started or stopped the pipe
    private void OnApiStateChanged(object? sender, EventArgs e) => DispatcherQueue.TryEnqueue(Load);

    // Show The Saved Values And The Approved Apps (newest last, like they were approved)
    private void Load()
    {
        var s = _context.Calendar.Settings;
        _loading = true;
        AllowSwitch.IsOn = s.AllowApiConnections;
        NameTakenRow.Visibility = s.AllowApiConnections && _context.Services.ApiNameTaken ? Visibility.Visible : Visibility.Collapsed;
        NoAppsText.Visibility = s.ApprovedApps.Count == 0 ? Visibility.Visible : Visibility.Collapsed;

        AppsList.Children.Clear();
        for (var i = 0; i < s.ApprovedApps.Count; i++)
        {
            var app = s.ApprovedApps[i];
            var remove = new Button { Content = "Remove" };
            AutomationProperties.SetName(remove, $"Remove {app.Name}");
            AutomationProperties.SetAutomationId(remove, $"ApiRemoveButton_{i}");
            var path = app.Path;
            remove.Click += (_, _) => _context.Save(x => x.WithoutApprovedApp(path));
            AppsList.Children.Add(new SettingRow { Glyph = "\uE737", Header = app.Name, Description = app.Path, Content = remove });
        }

        _loading = false;
    }

    private void OnAllowToggled(object sender, RoutedEventArgs e)
    {
        if (!_loading)
        {
            var on = AllowSwitch.IsOn;
            _context.Save(s => s with { AllowApiConnections = on });
        }
    }

    private void OnDocsClick(object sender, RoutedEventArgs e) => _ = _context.Services.LaunchAsync(DocsUri);
}
```

```csharp
    private static async Task<JsonElement> SendAsync(Stream pipe, StreamReader reader, int id, string method, string paramsJson = "{}")
    {
        var line = $$"""{"jsonrpc":"2.0","id":{{id}},"method":"{{method}}","params":{{paramsJson}}}""" + "\n";
        await pipe.WriteAsync(Encoding.UTF8.GetBytes(line), TestContext.Current.CancellationToken);
        await pipe.FlushAsync(TestContext.Current.CancellationToken);
```

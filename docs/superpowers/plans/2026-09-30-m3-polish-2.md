## Review Focus

1. **Late undo while the delete is still queued.** You delete offline, wait past the 6 s hold, then press Ctrl+Z. The delete may still be sending, so it must stay queued, and the copy must wait behind it (`DependsOn`). Otherwise Google could see the copy's create before the original's delete, or the copy could be dropped silently. Test: `EventEditorTests.Undo_AfterHoldEnds_KeepsTheDeleteAndQueuesTheCopyBehindIt` (Task 1).
2. **Two deletes, then Ctrl+Z twice.** The second Ctrl+Z must bring back the older delete. It must not undo the same delete twice or throw on a used receipt. Tests: `EventEditorTests.Undo_SameReceiptTwice_SecondDoesNothing` (Task 1) and `EditingTests.CtrlZ_Twice_UndoesTwoDeletesNewestFirst` (Task 6).
3. **Hostile contact data.** Contact names or emails from Google can be anything anyone typed:
   - control and bidi characters (`‮`)
   - markup
   - 5,000-character names
   - addresses that aren't addresses

   Suggestions must show plain, trimmed text, and only valid addresses can become guests. Tests: `ContactSearchTests.Search_DropsInvalidEmailsAndStripsControlCharacters` (Task 3) and `ConferencingAndContactsTests.GuestInput_HostileContactName_ShowsAsPlainText` (Task 11).
4. **People API not enabled in the user's Cloud project.** Google answers `403` with reason `SERVICE_DISABLED` or `accessNotConfigured`. That's not a consent problem. The editor must say "Turn on the People API in Google Cloud Console" instead of looping through re-sign-in. Test: `ContactSearchTests.Search_PeopleApiDisabled_ReportsApiDisabledNotConsent` (Task 3).
5. **Adding Meet offline, then a dropped response on retry.** The `createRequest.requestId` is fixed when the edit is queued, so a retried send reuses it and Google makes one link, not two. Test: `OutboxSenderTests.Send_ConferenceCreateRetried_SameRequestId` (Task 2).

### Task 1: Late Undo Re-Creates Quietly (Core)

Owner items: "Pressing Ctrl+Z should still undo the event, even if the toast has expired" (Core half), and the "re-create quietly" decision.

**Files:**
- Modify: `src/LeafCalendar.Core/Editing/EventEditor.cs` (`DeleteReceipt`, `Delete`, `DeleteCore`, `Undo`, class remarks)
- Modify: `src/LeafCalendar.Core/Editing/EventJson.cs` (add `QuietCopy`)
- Modify: `src/LeafCalendar.Core/Editing/RecurrenceEdits.cs` (add `ExDateLine`)

- Test: `tests/LeafCalendar.Tests/EventEditorTests.cs`, `tests/LeafCalendar.Tests/EventJsonTests.cs`, `tests/LeafCalendar.Tests/RecurrenceEditsTests.cs`

**What changes from the old rule:**
- Old: `Undo` returned `false` unless every entry was still `Pending` with `NotBefore > now` (`EventEditor.cs:154-156`).
- New: that case is unchanged (a true undo: put the snapshots back, drop the entries). In every other case, `Undo` brings each deleted item back without touching the delete entry, which may already be at Google or on its way:

| What was deleted (`DeleteKind`) | Late undo |
|---|---|
| `Event`: a single event, or a whole series (the entry is a `Delete` of that ID) | `AddCreate` of `EventJson.QuietCopy(masterRow, EventIds.NewId())`, with `sendUpdates: false`. For a series, the snapshot's canceled exception rows become `EXDATE` lines on the copy. Its **modified** exceptions are not re-created (see the `ponytail:` note). |
| `Instance`: one instance of a repeating event (a `Delete` of its instance ID) | A true restore. `EventStore.Restore` puts back the instance snapshot, which drops the local canceled row. Then queue a `Patch` of `{"status":"confirmed"}` on the instance ID with `ifMatch: null` (the documented "instance" exception) and `sendUpdates: false`. |
| `Following`: "This and following" (a `Patch` ending the master's repeat) | A true restore. Take the master's current `Etag`, `EventStore.Restore` the master snapshot, set that `Etag` back on the restored row (`EventStore.SetEtag`), then queue a `Patch` of `{"recurrence": <snapshot master's lines>}` with that etag and `sendUpdates: false`. When the first patch is still queued, the sender's same-event etag rebase handles it. |

- In every late case, if the original entry is **still in the outbox** (`OutboxStore.Get` is not null and its state is `Pending`), the new entry gets `DependsOn: entry.Seq`, so it waits behind the delete. If the delete is later refused, the sender drops the dependents, and its rejection path restores the original.
- A receipt can be used once. `Undo` records its seqs in a private `HashSet<long> _undone` and returns `UndoResult.Nothing` the second time.

**Interfaces:**
- Consumes: `EventStore.Snapshot` / `Restore` / `SetEtag`, `OutboxStore.Get` / `Add` / `Remove`, `EventIds.NewId()`, `EventJson.CloneForCreate`, `EventJson.RecurrenceOf`, and the private `AddCreate` / `AddPatch` helpers (`EventEditor.cs:434-462`).
- Produces (later tasks use these names verbatim):
  - `public enum DeleteKind { Event, Instance, Following }`
  - `public sealed record DeletedItem(OutboxEntry Entry, DeleteKind Kind);`
  - `public sealed record DeleteReceipt(IReadOnlyList<long> Seqs) { public IReadOnlyList<DeletedItem> Items { get; init; } = []; }`
  - `public enum UndoResult { Nothing, Restored, Recreated }` (`Restored` = the in-hold true undo, which sends nothing; `Recreated` = the late path, which sends quiet writes)
  - `public UndoResult EventEditor.Undo(DeleteReceipt receipt)`
  - `public static string EventJson.QuietCopy(string rawJson, string newId)`
  - `public static string RecurrenceEdits.ExDateLine(DateTimeOffset originalStart, bool isAllDay)`
  - Note for Task 2: `QuietCopy` keeps `conferenceData` (without `createRequest`), so the copy keeps its Meet link. Task 2 makes the client send `conferenceDataVersion=1` for any body that carries `conferenceData`.

    /// Brings a delete back. While every entry is still held (<see cref="UndoWindow"/>), the snapshots are put back
    /// and nothing is sent (<see cref="UndoResult.Restored"/>). After that the delete may be at Google already, so it is
    /// left alone and each item comes back quietly (<see cref="UndoResult.Recreated"/>, no emails): a copy with a new
    /// ID for an event or a whole series, a restore for one instance or "this and following". Each receipt works once.
    /// </summary>
    public UndoResult Undo(DeleteReceipt receipt)
    {
        var result = UndoResult.Nothing;
        var now    = time.GetUtcNow();
        InTransaction((conn, tx) =>
        {
            // Each Receipt Works Once
            if (receipt.Seqs.Count == 0 || receipt.Seqs.Any(_undone.Contains))
            {
                return;
            }

            var entries = receipt.Seqs.Select(seq => OutboxStore.Get(conn, tx, seq)).ToList();

            // Still Held: Put The Rows Back (newest first, so each snapshot lands on the state it was taken from)
            if (entries.All(e => e is { State: OutboxState.Pending, NotBefore: { } notBefore } && notBefore > now))
            {
                foreach (var entry in Enumerable.Reverse(entries))
                {
                    EventStore.Restore(conn, tx, entry!.AccountId, entry.CalendarId, entry.EventId, entry.BeforeJson ?? "[]");
                    OutboxStore.Remove(conn, tx, entry.Seq);
                }

                result = UndoResult.Restored;
            }
            else
            {
                // Late: Bring Each One Back Quietly
                foreach (var item in receipt.Items)
                {
                    var queued = OutboxStore.Get(conn, tx, item.Entry.Seq) is { State: OutboxState.Pending } ? item.Entry.Seq : (long?)null;
                    BringBack(conn, tx, item, queued);
                }

                result = UndoResult.Recreated;
            }

            foreach (var seq in receipt.Seqs)
            {
                _undone.Add(seq);
            }
        });

        return result;
    }

    static void BringBack(SqliteConnection conn, SqliteTransaction tx, DeletedItem item, long? dependsOn)
    {
        var e    = item.Entry;
        var rows = JsonNode.Parse(e.BeforeJson ?? "[]")!.AsArray().OfType<JsonObject>().ToList();

/// <summary>What a search found.</summary>

/// <summary>
/// Guest autocomplete from the People API: your contacts, then "other contacts" (people you've emailed), read-only.
/// </summary>
/// <remarks>
/// Results are untrusted text: control and format characters are removed, names are capped, and only addresses that
/// parse exactly are kept. Nothing is stored; logs carry the account ID and HTTP status only.
/// </remarks>
/// <seealso href="https://developers.google.com/people/api/rest/v1/people/searchContacts"/>
/// <seealso href="https://developers.google.com/people/api/rest/v1/otherContacts/search"/>
public sealed class ContactSearch(HttpClient http, AccessTokenProvider tokens, AppLog log, GoogleEndpoints? endpoints = null)
{
    /// <summary>Most suggestions returned.</summary>
    public const int MaxResults = 8;

    const int MaxQuery = 100;
    const int MaxName  = 100;
    const int MaxEmail = 254;

    readonly Uri _root = (endpoints ?? GoogleEndpoints.Default).PeopleApi;

    /// <summary>Searches both sources; never throws for Google or network errors (returns empty).</summary>
    public async Task<ContactResults> SearchAsync(string accountId, string query, CancellationToken ct)
    {
        // Nothing To Search
        query = query.Trim();
        if (query.Length is 0 or > MaxQuery)
        {
            return new([], ContactAccess.Allowed);
        }

        // Which Sources The Grant Allows
        var contacts = await tokens.HasScopeAsync(accountId, GoogleOAuthClient.ContactsScope, ct);
        var others   = await tokens.HasScopeAsync(accountId, GoogleOAuthClient.OtherContactsScope, ct);
        if (!contacts && !others)
        {
            return new([], ContactAccess.NeedsConsent);
        }

        var escaped = Uri.EscapeDataString(query);
        var found   = new List<Contact>();
        foreach (var path in new[]
                 {
                     contacts ? $"people:searchContacts?query={escaped}&readMask=names,emailAddresses&pageSize=10" : null,
                     others ? $"otherContacts:search?query={escaped}&readMask=names,emailAddresses&pageSize=10" : null,
                 })
        {
            if (path is null)
            {
                continue;
            }

            var (page, access) = await GetAsync(accountId, path, ct);
            if (access != ContactAccess.Allowed)
            {
                return new([], access);
            }

            found.AddRange(Clean(page));
        }

        return new([.. found.DistinctBy(c => c.Email, StringComparer.OrdinalIgnoreCase).Take(MaxResults)], ContactAccess.Allowed);
    }
}
